# 本地观测目录

本目录保存观测配置示例、简明说明及原地受保护 SQLite 数据；Python API、聚合和存储实现属于 backend 产品包。

真实 .env、ingestion token、数据库和日志不进入 Git、截图或源码备份。只接收允许的安全元数据，不保存项目正文、模型输入输出、工具载荷或凭据。

启动命令、配置角色、Windows token 共享、七天/100000 行保留策略及故障边界统一维护在[项目设计](../docs/project-design.md#configuration)。已执行检查与限制见[验证历史](../docs/validation-history.md#iteration-7)。
